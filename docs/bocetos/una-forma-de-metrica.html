Hub › Pauta

Una métrica, una forma

Una sola pieza, la Cifra, igual en todo el Hub. A la vista lleva solo lo necesario para leerla en un segundo; todo lo demás (la fórmula, qué es cada número, cada etiqueta, los filtros y la lista) aparece al hacer clic.

La tarjeta y lo que abre

Cada número tiene su rótulo: «de 900» es la meta y «a hoy 558» marca lo que deberíamos llevar. Lo rayado es el atraso. Clic en la tarjeta para abrirla como en la app.

Tres tamaños, la misma pieza

Tarjeta para lo principal de un bloque, barra para el cumplimiento y celda dentro de una tabla. Las tres abren la misma explicación.

Los casos raros, resueltos una vez

Hoy cada bloque los resuelve a su manera. Con la Cifra salen siempre igual, y al abrirlos dicen qué significan.

Para construirla

Especificación para discutir. Lo arma el servidor; la pantalla solo la pinta, así la explicación y la cifra no se pueden separar.

CifraDeMetrica {
  concepto      // clave del registro de métricas: de ahí salen nombre, "qué mide", fórmula y variables
  universo      // "paid" | "todas"
  valor         // número | null  (null = "—", siempre con motivo en palabras)
  unidad        // conteo | COP | USD | porcentaje | veces
  partes?       // [numerador, denominador] con los que se calculó: para "con los números de esta cifra"
  periodo       // texto del periodo y los filtros con que se calculó
  cobertura     // { completa } | { parcial, motivo }
  enCurso?      // el periodo no ha cerrado
  comparacion?  // { referencia, valor }   (solo si se pidió comparar)
  estado?       // { tono, fuente: "esperado" | "objetivo", umbrales }
  avance?       // { llevamos, meta, esperado, fraccionDeTiempo }
  lista         // la lista detrás de la cifra; sin lista, la cifra no se muestra
}

    DM-8 · Agenda, cita confirmada y llamada: una sola cosa con estados

    Recomendación. Hoy «agenda», «cita», «llamada» y «agendas del día» se usan como si fueran cosas distintas, y el Excel no cuadra con ninguna de las tres que mide el CRM. Propuesta: existe un solo objeto, la cita, que pasa por estados.

    Agendada→ Confirmada (nuevo)→ Realizadao No asistió· Reagendada· Cancelada
    MétricaQué cuentaCon qué fechaQuién la usa
    AgendadasCitas creadasEl día en que el lead reservóPauta: es lo que compra la inversión (costo por agenda)
    Citas del díaCitas programadas para ese díaEl día de la llamadaComercial: la carga del día de cada closer
    ConfirmadasDe las citas del día, las que el lead confirmóEl día de la llamadaComercial: el closer marca «confirmó» cuando el lead dice que va
    RealizadasDe las citas del día, las que ocurrieronEl día de la llamadaLas dos: base del % de show y del cierre
    Agendas según MetaLo que reporta el pixelEl día en que Meta la vioPauta, solo para revisar la medición, nunca como dato de negocio

    Consecuencia: «llamada» deja de ser una métrica (una llamada es una cita realizada) y por eso el número del día nunca cuadra: las 30 agendadas hoy y las 8 realizadas hoy son citas distintas, porque las de hoy se reservaron días antes. Para el Excel, «Agendas del día» = Agendadas y «Llamadas realizadas» = Realizadas. Falta que Michael y Paid Media confirmen que eso es lo que querían decir; si sí, se escribe en el vocabulario y en el diccionario, y «Confirmada» entra al pipeline comercial como estado nuevo de la cita.
