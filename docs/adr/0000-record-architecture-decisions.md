# Record architecture decisions

We record significant, hard-to-reverse architectural decisions as ADRs in this directory, numbered sequentially (`0001-slug.md`, `0002-slug.md`, …).

An ADR can be a single paragraph: what the context was, what we decided, and why. The value is recording *that* a decision was made and *why* — not filling out sections.

Only record a decision when all three are true: it's hard to reverse, it would surprise a future reader, and it was a real trade-off with genuine alternatives. `/grill-with-docs` and `/improve-codebase` offer to write these at the right moments.
